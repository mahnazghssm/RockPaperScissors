# Rock Paper Scissors Game

A simple Python implementation of the classic Rock, Paper, Scissors game. You can play against the computer, which randomly chooses rock, paper, or scissors.

## Features

- Play against the computer
- Computer makes a random choice
- Checks the winner of each round
- Allows you to play multiple rounds
- Uses a class-based structure

## Project Structure

```text
.
├── .gitignore
├── README.md
└── src
    └── game.py
```

- `src/game.py`: contains the game class and logic
- `.gitignore`: files and folders ignored by Git
- `README.md`: project documentation

## Requirements

- Python 3.9 or later

No external packages are required.

## Running the Project

Run the game from the project root:

```bash
python src/game.py
```

Then choose `rock`, `paper`, or `scissors` when prompted.
